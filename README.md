# 두사탈 · DUSATAL: Escape the Mole Company

두더지 회사 탈출하기. 훼손된 회사 '야사'의 빈칸을 추론으로 복원해 압박 면접실을 빠져나오는 2D 탈출 게임입니다.

> 이 저장소는 **빌드 배포 전용**입니다. 게임 파일은 [Releases](../../releases)에서 받을 수 있습니다.

## 플레이 방법 (Windows)
1. [최신 릴리스](../../releases/latest)에서 `Dusatal-x.y.z-win64.zip`을 받습니다.
2. 압축을 풀고 `Dusatal.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (아직 코드 서명이 없는 테스트 빌드입니다)

- 1화 「면접의 장」 · 약 25~30분
- 저장 위치: `%USERPROFILE%\AppData\LocalLow\Dusatal\두사탈`
- 요구 사항: Windows 10/11 64비트

## 테스트 빌드 안내
개발 중인 버전이라 막히는 곳이나 오류가 있을 수 있습니다. 이 저장소의 [Issues](../../issues)에 남겨 주세요.
