# 두사탈 · DUSATAL: Escape the Mole Company

두더지 회사 탈출하기. 훼손된 회사 '야사'의 빈칸을 추론으로 복원해 압박 면접실을 빠져나오는 2D 탈출 게임입니다.

> 이 저장소는 **빌드 배포 전용**입니다. 게임 파일은 [Releases](../../releases)에서 받을 수 있습니다.

## 바로 플레이 (설치 없음, 권장)
**▶ https://tjfruddnjs1.github.io/dusatal-releases/play/**
PC(Windows·Mac)의 크롬·엣지·사파리에서 가장 잘 됩니다. 모바일 브라우저는 가로 화면으로 플레이해 주세요. 진행은 브라우저에 저장됩니다.

## 다운로드해서 플레이 (Windows)
1. [최신 릴리스](../../releases/latest)에서 `Dusatal-x.y.z-win64.zip`을 받습니다.
2. 압축을 풀고 `Dusatal.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (아직 코드 서명이 없는 테스트 빌드입니다)

- 1화 「면접의 장」 · 약 25~30분
- 저장 위치: `%USERPROFILE%\AppData\LocalLow\Dusatal\두사탈`
- 요구 사항: Windows 10/11 64비트

## 랭킹과 기록
**https://dusatal-api.tjfruddnjs22.workers.dev/**
엔딩별 최단 클리어 시간 순위입니다. 게임 타이틀의 '기록과 기기 연결'에서 내 기록 페이지를 열고, 연결 코드로 다른 기기(PC, 웹)에서 이어 할 수 있습니다.
세이브와 기록은 기기에 먼저 저장되고 인터넷에 연결되면 자동으로 백업됩니다. 이름 외의 개인정보는 받지 않습니다.
